## Key classes

- **`OverlapSelector`** (ABC): `select_overlap(P, valid_clusters) -> List[List[int]]`.
  All four strategies implement the same interface and are interchangeable via
  `create_selector(strategy, membership_closeness=..., lam=...)`.
- **`ClusteringMachine`**: original Cluster-GCN decomposition. Accepts an
  optional cached DANMF result so it can share memberships with adaptive runs.
- **`AdaptiveWMCClusteringMachine`**: same partitioning logic but drives
  overlap assignment through the selected `OverlapSelector`.
- **`ClusterGCNTrainer`**: per-cluster mini-batch training; `test()` returns
  `{"micro": ..., "macro": ...}`.

## Shared experiment pipeline (`experiment_utils.py`)

`run_single(graph, features, target, args, method, danmf_result=None)`:
1. seeds torch/numpy/random from `args.seed`
2. builds the appropriate clustering machine for `method`
3. decomposes using the cached DANMF result (or fits a fresh one)
4. trains and returns micro/macro F1, runtime, and overlap ratio

`fit_danmf_cached(graph, args, seed)` fits DANMF **once** per (dataset, seed);
all methods on that seed then share identical community memberships — a clean
paired design for statistical testing.

## Running experiments

```bash
python src/run_fixed_wmc_comparison.py --seeds 20   # main significance study
python src/run_full_experiments.py --seeds 10       # overview across methods
python src/run_ablation.py --seeds 10               # λ sensitivity
python src/run_full_ambiguity_analysis.py           # node-level analysis + plots
python src/main.py --dataset-name Cora              # single run
```

## Conventions

- Scripts run from the repo root; `src/` is added to `sys.path` internally.
- Results are written to `results/` as raw + summary CSVs.
- Paper figures are generated by `adaptive-ocgcn-latex/generate_plots.py`
  (edit `OUTPUT_DIR` at the top if paths change).
